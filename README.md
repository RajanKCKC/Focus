# Focus Timer

A clean and simple focus timer with relaxing ambient sounds to help you stay productive.

## [Live Demo](https://rajankckc.github.io/Focus/)

## Features

- **Configurable Timer**: Start, pause, reset, and easily add or subtract time in 5-minute increments.
- **Ambient Soundscapes**: Toggle between Forest, Rain, Fireplace, and Coffee Shop sounds.
- **Independent Volume Controls**: Adjust the volume level for each ambient background track.
- **Light & Dark Themes**: Switch between light and dark modes with persistent theme memory.
- **Lightweight & Fast**: Built with pure HTML, CSS, JavaScript, and standard Web Audio.

## How to Run

1. Open `index.html` in any modern web browser or start a local HTTP server:
    ```bash
        python -m http.server 3000
    ```
2. Navigate to `http://localhost:3000` in your browser.
