# Focus Timer

A clean and simple focus timer with relaxing ambient sounds to help you stay productive.

### [Live Demo](https://rajankckc.github.io/Focus/)

### AI Usage: style.css and used guides to make this project.

## Features

- **Configurable Timer**: Start, pause, reset, and easily add or subtract time in 5-minute increments.
- **Ambient Soundscapes**: Toggle between Forest, Rain, Fireplace, and Coffee Shop sounds.
- **Independent Volume Controls**: Adjust the volume level for each ambient background track.
- **Light & Dark Themes**: Switch between light and dark modes with persistent theme memory.
- **Lightweight & Fast**: Built with pure HTML, CSS, JavaScript, and standard Web Audio.

## How to Run

No installation or build steps required.

1. Clone the repository:

```bash

git clone https://github.com/RajanKCKC/Focus.git

cd Focus

```

2. Open `index.html` directly in your browser, or start up a simple local server:

```bash

python -m http.server 3000

```


3. Visit `http://localhost:3000` in your browser.

---

## How It Works

* **Audio Engine**: Utilizes native HTML5 audio elements to allow seamless background sound mixing without external dependencies.
* **State & Storage**: Simple browser `localStorage` tracks theme preferences across sessions.
